WalkDroid は ZX300A に Android の画面、アプリ、音声設定を提供します。音声・無線機能には各自の端末から取得した Sony のコンポーネントを使用します。本プロジェクトは実験段階にあり、Sony、LineageOS、Walkman One の作者とは無関係です。

**はじめに**

1. クリーンな Walkman One を導入済みの ZX300A を用意し、[非公開コンポーネントの取得とビルド](docs/BUILDING.ja.md)に従って、端末の純正ファイル、Arm グラフィックスドライバー、ビルド環境を準備します。
2. [パーティションとインストール](docs/INSTALL.ja.md)に従って音楽領域をバックアップし、領域を準備してシステムをインストールし、パソコンから起動します。

**現在の機能範囲**

| 機能 | 確認済みの範囲 |
| --- | --- |
| システムと画面 | Android デスクトップ、アプリ一覧、音声設定、排他アプリの選択を実機で使用しています。画面は簡体字中国語、繁体字中国語、英語、日本語に対応しています。 |
| 3.5 mm | PCM と DSD64 から PCM に変換した音声を実機で再生しました。192 kHz 再生と 384 kHz 直接出力経路にも実機記録があります。 |
| USB DAC | 48 kHz 再生、リアルタイムの音量調整、終了後の復帰を実機で再検証しました。 |
| Bluetooth | 受信経路と 3.5 mm 出力を再検証し、ペアリング済み DAC への送信はユーザーが試聴しました。通常の送信プログラムは 2 回の再接続に成功しています。無音データ試験ではバッファ不足が 2 回記録されました。 |
| microSD | exFAT カードの読み取り専用アクセスを確認しました。 |
| 未完了 | 4.4 mm の実出力、ネイティブ DSD、物理ボタン、すべての抜き差し動作は実機での受け入れが完了していません。対象外のネットワーク項目は削除または無効化しています。 |

上記は以前の開発版の実機記録であり、すべての新しいビルドで同じ再検証が完了したことを意味しません。今回ソースから再構築した B116 は実機でデスクトップまで起動し、排他アプリ経由の 3.5 mm PCM で二つのテスト音を再生しました。終了時にバッファ不足が 1 回記録され、他の完成済み範囲はこのビルドで個別に再検証していません。音響効果の切り替えとプリセットは操作できますが、すべての効果・形式・聴感の組み合わせが検証済みという意味ではありません。Android は現在パソコンから Fastboot で RAM 起動し、再起動すると元のシステムに戻ります。オフラインのデュアルブートメニューはありません。現在のビルドは `userdebug` であり、セキュリティ認証を目的とした正式ファームウェアではありません。
